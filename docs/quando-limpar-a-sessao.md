# Quando limpar a sessão (`/clear`) em vez de continuar

Limpo a sessão quando um destes sinais aparece:
- O agente repete o mesmo erro depois de duas correções minhas: o contexto já está contaminado pela tentativa errada.
- Mudei de tarefa (ex.: de gerar o esqueleto para escrever o README): o histórico antigo só gasta contexto.
- O agente passa a ignorar uma regra do `CLAUDE.md` que seguia antes.

Antes de limpar, registro no `CLAUDE.md` o que aprendi, para a próxima sessão já começar certa.
